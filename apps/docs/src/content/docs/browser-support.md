nano-skeleton targets modern evergreen browsers:

<div class="table-wrap">

| Browser       | Version |
| ------------- | ------- |
| Chrome / Edge | 123+    |
| Safari        | 17.5+   |
| Firefox       | 127+    |

</div>

The versions come from
[`light-dark()`](https://developer.mozilla.org/docs/Web/CSS/color_value/light-dark)
(Chrome 123, Safari 17.5) and
[gradients interpolated in `oklch`](https://developer.mozilla.org/docs/Web/CSS/gradient/linear-gradient#interpolation_with_color_space_and_hue)
(Firefox 127).
